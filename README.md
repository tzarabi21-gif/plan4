# NEXA — سامانه هوشمند برنامه‌ریزی تحصیلی

نسخه پایه قابل اجرا و توسعه برای ایران؛ PHP 8.2+ / MySQL / PWA. رابط فارسی و راست‌چین، پوسته تیره نئونی.

## اجرا با XAMPP
1. پوشه `NEXA` را در `C:\xampp\htdocs\` کپی کنید.
2. Apache و MySQL را روشن کنید.
3. در phpMyAdmin یک دیتابیس با نام `nexa` بسازید و فایل `database/schema.sql` را Import کنید.
4. `config/config.php` را با اطلاعات MySQL خود تنظیم کنید.
5. به `http://localhost/NEXA/public/` بروید.

## اجرا با PHP داخلی
`php -S 127.0.0.1:8080 -t public` و سپس `http://127.0.0.1:8080`.

## انتشار Render
- این پروژه برای اجرای PHP در Docker آماده شده است.
- یک MySQL مدیریت‌شده بسازید و متغیرهای `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS` را در Render تنظیم کنید.
- متغیر `APP_URL` را روی آدرس نهایی تنظیم کنید.
- `ADMIN_INITIAL_PASSWORD` را فقط در Environment Variables وارد کنید؛ آن را در کد یا Git قرار ندهید.
- پس از ساخت دیتابیس، `database/schema.sql` را اجرا کنید.
- دیسک محلی Render پایدار نیست؛ فایل‌های کاربران باید در نسخه عملیاتی به Object Storage متصل شوند.

## ورود مدیر اولیه
مدیر اولیه از طریق `scripts/create_admin.php` ساخته می‌شود. متغیرهای `ADMIN_INITIAL_PASSWORD` و `ADMIN_INITIAL_MOBILE` باید در محیط سرور تنظیم شوند. رمز به‌صورت hash ذخیره می‌شود. رمز عبور در فایل سورس قرار نگرفته است.

## وضعیت یکپارچه‌سازی‌ها
- OTP پیامکی: لایه اتصال در `app/Services/SmsGateway.php` آماده اتصال به پنل پیامکی ایران است؛ تا زمانی که کلید/الگوی پنل تنظیم نشود، کد در محیط توسعه فقط در لاگ سرور ثبت می‌شود.
- AI: چند ارائه‌دهنده از طریق تنظیمات محیطی قابل اتصال‌اند؛ کلید API باید سمت سرور نگهداری شود.
- پرداخت: فعلاً غیرفعال؛ جدول تنظیمات و قابلیت آماده‌سازی برای درگاه در نظر گرفته شده است.
- آفلاین: PWA و کش پوسته و فایل‌های استاتیک؛ همگام‌سازی داده‌های حساس/تغییرات چنددستگاهی نیازمند اتصال اینترنت است.

## امنیت
HTTPS، رمزهای قوی، تغییر رمز اولیه، کلیدهای محرمانه، پشتیبان‌گیری، محدودیت درخواست OTP و تنظیم مجوز مدیران فرعی قبل از استفاده عمومی الزامی است. این بسته نقطه شروع عملیاتی و قابل توسعه است و اتصال سرویس‌های پیامک، AI و پرداخت بدون کلید و حساب ارائه‌دهنده فعال نمی‌شود.
